# Tip Calculator - Flutter Lab Project

## Description
A simple Flutter mobile application that calculates tip amount, total bill,
and amount payable by each person.

## Features
- Enter bill amount
- Select tip percentage
- Increase/decrease number of people
- Calculate tip amount
- Calculate total amount
- Calculate amount per person
- Reset all inputs

## How to Run

1. Install Flutter and Android Studio/VS Code.
2. Open this project folder in Android Studio or VS Code.
3. Run:
   flutter pub get
4. Start an Android emulator or connect a physical Android device.
5. Run:
   flutter run

## Calculation
Tip Amount = Bill Amount × Tip Percentage ÷ 100

Total Amount = Bill Amount + Tip Amount

Per Person = Total Amount ÷ Number of People
